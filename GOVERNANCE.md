# Governance

Soneso maintains the project. Maintainers and contributors decide in issues and
pull requests on this repository, in the open. A maintainer merges a change
after the review that [CONTRIBUTING.md](CONTRIBUTING.md) describes.

A contributor is anyone with a merged pull request. The release notes name the
contributors of each release. After three merged pull requests, a contributor
can ask for the triage role in an issue: labels, assignments, and closing
duplicates.

[MAINTAINERS.md](MAINTAINERS.md) lists the maintainers. An existing maintainer
proposes a new one in an issue, and Soneso confirms.
